# Secure Multi-Office Enterprise Network — Interview Definitions

## 1. Project Overview

### What is your project?

> My project is a Secure Multi-Office Enterprise Network Infrastructure that simulates two branch offices, Pune and Mumbai. I implemented the environment using VMware Workstation Pro, pfSense, Windows Server with Active Directory, Ubuntu Server, and Windows clients. I configured network segmentation, firewall policies, static routing, and site-to-site VPN connectivity between the offices. For security, I used Fail2Ban and Suricata IDS/IPS, while Uptime Kuma and Nagios were used for monitoring. I also deployed a Dockerized website on an AWS EC2 instance to demonstrate cloud and DevOps integration.

# 2. Networking Fundamentals

## 2.1 What is a Computer Network?

> A computer network is a collection of interconnected devices that communicate with each other to exchange data and share resources using protocols such as TCP/IP.

**Example:** Your Pune and Mumbai offices are separate networks connected through a VPN.

---

## 2.2 What is LAN?

> LAN, or Local Area Network, is a network that connects devices within a limited geographical area such as an office, building, or campus.

**In your project:** Each branch office has its own LAN.

---

## 2.3 What is WAN?

> WAN, or Wide Area Network, connects geographically separated networks over a larger area such as cities, countries, or continents.

**In your project:** The Pune and Mumbai branch networks represent separate sites connected through a WAN-like connection.

---

## 2.4 What is an IP Address?

> An IP address is a logical address assigned to a network interface to identify a device and enable communication over an IP network.

**Example:**

```text
192.168.10.10
```

---

## 2.5 What is a Subnet?

> A subnet is a logically divided portion of an IP network. Subnetting allows an organization to divide a larger network into smaller networks for better management, security, and efficient IP address utilization.

---

## 2.6 What is a Subnet Mask?

> A subnet mask determines which portion of an IPv4 address represents the network and which portion represents the host.

**Example:**

```text
IP:          192.168.10.10
Subnet Mask: 255.255.255.0
CIDR:        /24
```

---

## 2.7 What is a Default Gateway?

> A default gateway is the device, usually a router or firewall, that forwards traffic from a local network to other networks.

**In your project:** pfSense acts as the gateway for the internal networks.

---

## 2.8 What is DNS?

> DNS, or Domain Name System, translates human-readable domain names into IP addresses.

**Example:**

```text
google.com → IP address
```

In an Active Directory environment, DNS is especially important because AD relies heavily on DNS for locating domain services.

---

## 2.9 What is DHCP?

> DHCP, or Dynamic Host Configuration Protocol, automatically provides network configuration such as IP address, subnet mask, default gateway, and DNS server to clients.

---

# 3. Routing

## 3.1 What is Routing?

> Routing is the process of selecting a path and forwarding packets from a source network to a destination network.

---

## 3.2 What is a Router?

> A router is a Layer 3 networking device that forwards packets between different IP networks based on routing information.

---

## 3.3 What is Static Routing?

> Static routing is a routing method where routes are manually configured by an administrator instead of being dynamically learned through a routing protocol.

**Example:**

Suppose:

```text
Pune LAN:    192.168.10.0/24
Mumbai LAN:  192.168.20.0/24
```

A route can tell the Pune firewall:

```text
192.168.20.0/24 → Mumbai VPN/interface
```

---

## 3.4 Static Routing vs Dynamic Routing

| Static Routing | Dynamic Routing |
|---|---|
| Manually configured | Learned automatically |
| Simple networks | Large networks |
| Less overhead | More protocol overhead |
| Does not automatically adapt | Can adapt to topology changes |
| Example: manually configured route | OSPF, BGP, EIGRP |

---

# 4. Firewall

## 4.1 What is a Firewall?

> A firewall is a security device or software that monitors and controls network traffic based on predefined security rules.

---

## 4.2 What is pfSense?

> pfSense is an open-source firewall and router platform based on FreeBSD. It provides features such as firewall filtering, routing, NAT, VPN, DHCP, DNS services, and network monitoring.

---

## 4.3 Why did you use pfSense?

> I used pfSense as the network security gateway for each branch. It allowed me to implement firewall rules, routing, NAT, VPN connectivity, and network segmentation between different network zones.

---

## 4.4 What is a Firewall Rule?

> A firewall rule defines whether specific network traffic should be allowed or denied based on parameters such as source IP, destination IP, protocol, and port.

**Example:**

```text
Source:      LAN
Destination: Internet
Protocol:    TCP
Port:        443
Action:      Allow
```

---

## 4.5 What is a Stateful Firewall?

> A stateful firewall tracks the state of network connections and uses that information when deciding whether packets should be allowed.

For example, if an internal client initiates an HTTPS connection, the firewall can recognize the returning traffic as part of the established connection.

---

# 5. NAT

## What is NAT?

> NAT, or Network Address Translation, translates private IP addresses into public IP addresses or vice versa.

**Example:**

```text
192.168.10.50
      ↓
    pfSense
      ↓
  Public IP
```

NAT allows multiple internal devices to share a public IP address.

---

## What is PAT?

> PAT, or Port Address Translation, allows multiple private devices to share a single public IP by differentiating connections using port numbers.

PAT is commonly called **NAT overload**.

---

# 6. VPN

## 6.1 What is VPN?

> A VPN, or Virtual Private Network, creates an encrypted communication tunnel over an untrusted network such as the Internet.

---

## 6.2 What is Site-to-Site VPN?

> A site-to-site VPN securely connects two networks so that devices in one office can communicate with devices in another office through an encrypted tunnel.

**Architecture:**

```text
Pune LAN
   |
pfSense
   |
Encrypted VPN Tunnel
   |
pfSense
   |
Mumbai LAN
```

---

## 6.3 What is OpenVPN?

> OpenVPN is an open-source VPN solution that can create encrypted tunnels using SSL/TLS and cryptographic mechanisms for secure communication.

### Why use OpenVPN?

> I used OpenVPN to securely connect the Pune and Mumbai branch networks so that internal resources could communicate across the sites without exposing their traffic directly to the Internet.

# 7. Network Segmentation

## What is Network Segmentation?

> Network segmentation is the practice of dividing a network into separate logical or physical segments to improve security, performance, and access control.

**Example:**

```text
Users Network
      |
Servers Network
      |
Management Network
```

Instead of allowing unrestricted communication between all segments, firewall rules control which traffic is permitted.

### Why is segmentation important?

- Reduce attack surface
- Limit lateral movement
- Improve access control
- Isolate sensitive systems
- Improve network management

---

# 8. VLAN

## What is VLAN?

> A VLAN, or Virtual Local Area Network, logically separates devices into different Layer 2 networks even when they use the same physical switching infrastructure.

**Example:**

```text
VLAN 10 → Users
VLAN 20 → Servers
VLAN 30 → Management
```

### Important interview distinction

**Network segmentation** is the broader security concept.

**VLAN** is one technology used to implement network segmentation.

# 11. Active Directory

## 11.1 What is Active Directory?

> Active Directory Domain Services, or AD DS, is Microsoft's directory service that centrally manages users, computers, groups, authentication, and access control within a Windows domain.

---

## 11.2 What is a Domain?

> A domain is a logical administrative boundary in Active Directory where users, computers, and other resources are centrally managed.

**Example:**

```text
company.local
```

---

## 11.3 What is a Domain Controller?

> A Domain Controller is a Windows Server running Active Directory Domain Services that authenticates users and computers and provides directory services for the domain.

---

## 11.4 What is Authentication?

> Authentication is the process of verifying the identity of a user, device, or service.

```text
Username + Password
       ↓
Authentication
       ↓
Identity verified
```

---

## 11.5 What is Authorization?

> Authorization determines what an authenticated user or system is allowed to access or perform.

**Simple distinction:**

```text
Authentication → Who are you?
Authorization  → What are you allowed to do?
```

---

## 11.6 What is Group Policy?

> Group Policy is an Active Directory feature that allows administrators to centrally configure and enforce settings for users and computers.

**Examples:**

- Password policies
- Account lockout policies
- Security settings
- Software restrictions
- Windows configuration

---

## 11.7 What is an OU?

> An Organizational Unit, or OU, is a container in Active Directory used to organize users, computers, and other objects and apply policies to them.

# 13. IDS and IPS

## 13.1 What is IDS?

> IDS, or Intrusion Detection System, monitors network or system activity for suspicious behavior and generates alerts when potential threats are detected.

**IDS = Detect and Alert**

---

## 13.2 What is IPS?

> IPS, or Intrusion Prevention System, detects malicious or suspicious traffic and can actively block or prevent it.

**IPS = Detect + Prevent**

---

## 13.3 IDS vs IPS

| IDS | IPS |
|---|---|
| Detects threats | Detects and blocks threats |
| Usually passive | Usually inline |
| Generates alerts | Can take prevention actions |
| Does not normally stop traffic | Can stop malicious traffic |

---

# 14. Suricata

## What is Suricata?

> Suricata is an open-source network threat detection engine that supports IDS, IPS, and network security monitoring.

---

## How does Suricata work?

```text
Network Traffic
       ↓
   Suricata
       ↓
Rule Inspection
       ↓
Suspicious?
   ↙       ↘
 Yes        No
 ↓           ↓
Alert/Block  Allow
```

---

## What are Suricata Rules?

> Suricata rules define patterns and conditions that the engine uses to identify suspicious or malicious network traffic.

---

# 15. Fail2Ban

## What is Fail2Ban?

> Fail2Ban is a Linux security tool that monitors log files for repeated failed authentication attempts or other suspicious activity and temporarily blocks the associated IP addresses.

**Example:**

```text
Attacker
   ↓
Repeated SSH login failures
   ↓
Log generated
   ↓
Fail2Ban detects pattern
   ↓
IP temporarily banned
```

---

## Fail2Ban vs Firewall

> The firewall primarily controls traffic based on configured network rules, while Fail2Ban dynamically reacts to suspicious behavior observed in application or service logs.

---

# 23. Docker

## What is Docker?

> Docker is a containerization platform that packages an application and its dependencies into a portable, isolated container.

---

## What is a Container?

> A container is an isolated process environment that shares the host operating system's kernel while packaging the application and its required dependencies.

---

## VM vs Container

| Virtual Machine | Container |
|---|---|
| Includes guest OS | Shares host kernel |
| More resource intensive | Lightweight |
| Stronger OS-level isolation | Process-level isolation |
| Slower startup | Fast startup |

---

# 24. Docker Image

> A Docker image is a read-only template containing the application code, dependencies, libraries, and configuration required to create a container.

---

# 25. Dockerfile

> A Dockerfile is a text file containing instructions used to build a Docker image.

**Example:**

```dockerfile

COPY website /usr/share/nginx/html

```

# 26. Docker Container vs Image

> An image is the template, while a container is a running instance created from that image.

**Simple analogy:**

```text
Docker Image     → Blueprint
Docker Container → Running building
```

---

# 33. UDP

---

```text
Client              Server

  SYN   ----------->
        <----------- SYN-ACK
  ACK   ----------->
```

---

> Defense in depth is a security strategy that uses multiple layers of security controls so that failure of one control does not completely compromise the system.

**Your project demonstrates this concept through:**

```text
Firewall
   +
Network Segmentation
   +
VPN
   +
Active Directory
   +
Fail2Ban
   +
Suricata
   +
Monitoring
```

---

## Attack Surface

> Attack surface is the collection of exposed entry points that an attacker could potentially use to compromise a system or network.

**Examples:**

- Open ports
- Web applications
- Remote services
- VPN endpoints
- User accounts
- Public cloud services
